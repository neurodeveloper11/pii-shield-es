El problemaThe problem

Los textos en español están llenos de datos personales: respuestas a PQRS, correos, chats de soporte, contratos, hojas de cálculo. Antes de compartirlos con un tercero, analizarlos o enviarlos a un servicio de IA, hay que quitar esos datos, y hacerlo a mano no escala. Spanish-language text is full of personal data: complaint replies, emails, support chats, contracts, spreadsheets. Before sharing it with a third party, analyzing it or sending it to an AI service, that data has to go, and doing it by hand does not scale.

Formatos localesLocal formats

Muchas herramientas de detección de PII están pensadas sobre todo para inglés y formatos de EE. UU. Una cédula con puntos, un NIT con su dígito de verificación, una dirección «Cra 15 # 93-60» o un celular «+57 300…» exigen reglas propias. Many PII detection tools are designed mainly for English and US formats. A dotted cédula, a NIT with its check digit, an address like “Cra 15 # 93-60” or a “+57 300…” mobile number need purpose-built rules.

Sin enviar nada afueraNothing leaves your machine

Mandar el texto sin anonimizar a un servicio externo para anonimizarlo es justo lo que querías evitar. pii-shield-es corre sin red: reglas, listas y checksums, sin modelos pesados. Sending raw text to an external service so it can be anonymized defeats the purpose. pii-shield-es runs offline: rules, word lists and checksums, no heavy models.

Cómo funcionaHow it works

Cuatro pasos, todos deterministas y auditables. Four steps, all deterministic and auditable.

1

Reglas y contextoRules and context

Expresiones regulares y palabras clave («cédula», «NIT», «placa»…) localizan candidatos.Regular expressions and keywords (“cédula”, “NIT”, “placa”…) find candidates.

2

ValidaciónValidation

Dígito de verificación del NIT (DIAN), IBAN módulo 97 y CLABE descartan números que solo «se parecen».NIT check digit (DIAN), IBAN mod 97 and CLABE discard numbers that merely “look like” IDs.

3

ResoluciónResolution

Si dos detecciones se solapan, gana la de mayor confianza. Cada una trae su puntaje (heurístico).When two detections overlap, the higher-confidence one wins. Each carries a (heuristic) score.

4

ReemplazoReplacement

Etiqueta, máscara parcial o seudónimo; con tabla local, la seudonimización es reversible.Label, partial mask or pseudonym; with a local table, pseudonymization is reversible.

Instalación y usoInstall and use

Requiere Python 3.10 o superior. Aún no está en PyPI; se instala desde GitHub. Requires Python 3.10+. Not on PyPI yet; install it from GitHub.

InstalarInstall 
pip install "git+https://github.com/neurodeveloper11/pii-shield-es.git"
Desde PythonFrom Python 
from pii_shield_es import detect, anonymize, PseudonymTable

texto = "Mi cédula es 1.023.456.789 y mi correo es a@example.com"

detect(texto)                         # entidades con tipo, rango y puntaje
anonymize(texto)                      # "Mi cédula es [CEDULA] y mi correo es [CORREO]"
anonymize(texto, modo="mascara")      # enmascarado parcial

tabla = PseudonymTable()              # seudonimización reversible
anon = anonymize(texto, modo="seudonimo", tabla=tabla)
assert tabla.restore(anon) == texto
Desde la terminal (texto, .txt y .csv)From the terminal (text, .txt and .csv) 
pii-shield anonimizar "Mi cédula es 1.023.456.789"
pii-shield anonimizar -f clientes.csv --columnas nota -m mascara -o clientes_anon.csv
pii-shield anonimizar -f datos.csv -m seudonimo --tabla tabla.json -o datos_anon.csv
pii-shield restaurar -f datos_anon.csv --tabla tabla.json
pii-shield detectar -f clientes.csv --json

Límites y aviso legalLimits and legal notice

No sustituye una revisión de cumplimientoIt does not replace a compliance review

pii-shield-es es una ayuda técnica heurística: no garantiza detectarlo todo y no ofrece asesoría jurídica. Cumplir la Ley 1581 de 2012 (Habeas Data) implica mucho más que anonimizar texto. Revisa siempre el resultado y consulta a un profesional. pii-shield-es is a heuristic technical aid: it does not guarantee that everything is detected and offers no legal advice. Complying with Colombian Law 1581 of 2012 (Habeas Data) takes far more than anonymizing text. Always review the output and consult a professional.

  • Son reglas y listas, no un modelo de lenguaje: habrá falsos negativos y positivos.It is rules and word lists, not a language model: expect false negatives and positives.
  • Un nombre fuera de las listas solo se detecta con contexto («señor…», «nombre:»).A name outside the word lists is only detected with context (“señor…”, “nombre:”).
  • Un número de identificación sin palabra clave cerca no se marca (para no confundirlo con montos).An ID number with no nearby keyword is not flagged (to avoid confusing it with amounts).
  • La tabla de seudónimos contiene los datos originales: protégela. Los datos seudonimizados siguen siendo datos personales.The pseudonym table contains the original data: protect it. Pseudonymized data generally remains personal data.

Las métricas (precisión y recall por tipo) se miden con un script sobre un conjunto sintético y están en el README, junto con la lista completa de limitaciones: Per-type precision and recall are measured by a script on a synthetic set and published in the README, along with the full list of limitations: ver métricassee metrics · ver limitacionessee limitations
